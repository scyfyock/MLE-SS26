# bomberman_rl
Setup for a project/competition amongst students to train a winning Reinforcement Learning agent for the classic game Bomberman.

# Ideas so far
## Reward Shaping
Traditional simple RL problems can be run so that the agent attempts to reach the direction with each step resulting in
a -1 reward while getting to the object results in a 1 reward. The events can be used to designate rewards and attach numbers
to each of the events stated. Mainly the box exploded, collected coin, killed opponent giving high rewards but the killed
self event giving like -500 reward. 

## Implementing ligtweight World Model
The world model will be implemented using Dyna-Q learning. 
This combines direct learning from real interactions with planning based on simulated experiences generated by the learned model.

The basic project idea and the goal of training a strong reinforcement learning agent for Bomberman have been established.
Initial approaches to reward shaping have been collected. Game events such as destroying boxes, collecting coins, and defeating opponents should be rewarded positively.
Negative rewards, especially for self-destruction, should be weighted significantly more heavily.
Dyna-Q has been selected as an approach for a lightweight world model. It will combine real experiences with simulated planning steps.
